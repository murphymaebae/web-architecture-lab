# Web Architecture Lab

A hands-on sandbox for learning how modern enterprise web platforms are put together:
rendering strategies, content strategies, GraphQL, microservices vs monoliths,
customer journey management and omni-channel experiences.

The work is split into four steps. Each step lands as its own pull request with
a learning guide in [`docs/learning`](docs/learning).

1. **Web foundation** - Next.js + React, rendering strategies and content strategies
2. **Backend and GraphQL** - small services behind a GraphQL gateway, plus a monolith mode
3. **Journey management** - event tracking and "next best action" personalization
4. **Omni-channel** - a React Native (Expo) app on the same backend, and a comparison write-up
